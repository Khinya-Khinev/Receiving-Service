# Receiving Service

Microservice that handles ASN matching goods receiving, gives Inventory Service putaway tasks and reports discrepancies.

## Why?

To get hands-on experience and encounter complexity, problems to solve and grow. Sandbox to try out different interesting things.

## Tech Stack

Java 25, Spring Boot 4, PosgreSQL, Apache Kafka, Apache Maven, Redis(a lil bit)

## Getting Started

### Prerequisites

-   JDK 25 or later
-   Maven
-   Docker

### Running the Application

1.  **Start Application:**

    ```sh
    docker compose up
    ```
